# 实物制作与成品记录

四段播放器均使用上传至 GitHub 附件存储的 H.264／AAC 播放版本，点击即可播放；默认静音，点击扬声器按钮可开启声音。下载链接保留原始 HEVC／AAC 视频，可使用支持 HEVC 的播放器打开。
