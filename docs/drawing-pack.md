## 尺寸与覆盖范围

- 长 X：左右方向；宽 Y：前后方向；高 Z：上下方向。表中数值是装配姿态下的外包络，不按最大边自动排序。原点为机体左前方桌面基准，坐标表记录实体包络最小角。
- 各主要零件给出俯、正、右三个独立命名视图；不同视图可使用不同的标注比例。不是统一第一角或第三角投影排列。打印使用 **A3、100% 实际大小**，尺寸以标注数值为准。
- 厚度与长宽高分别列出。平板给板厚，防尘盖给壁厚；采购总成的未知壁厚或 PCB 厚度，以及实心件不适用的壁厚，明确写在说明中。
- 斜障板现在为真实法向厚 8 mm，矩形备料 426 × 98 × 8 mm，修上下 18° 斜口至安装竖高 90 mm。格栅为 426 × 7 × 3 mm 矩形条，整体后倾 18°、竖向节距 11 mm。
- 木板零件页另列整数备料 L × W × T；第一册汇总 21 块 / 条，同步输出[木板备料 CSV](../cad/wood-cut-list.csv)。备料尺寸不含锯缝、表面处理及装配余量；精确斜切边界和接口孔仍允许小数。
- 同形件采用代表件视图、数量与各安装位置；`AcousticRear` 和 `RearSupport` 各包含两个独立实体，按两块分别出图。
- 覆盖主模型 **65 个当前装配对象**，另有 **16 个历史参考对象**全部有附录尺寸记录。基线通用机芯在附录中按总成三视图及逐对象尺寸表表示；不与当前弯臂机芯同时安装。
- 诊断矩形包络及红色干涉体不是实物零件，不作为零件下料图；假设下探深度及剩余净空在机芯总图中记录。

第一册 A-P06 分别绘制固定叶和活动叶，各 2 件，两叶合计 1 只采购合页，共 2 只；没有独立采购铰链轴。新增 A-P08 为补偿垫片／内压板，第 16 页 A-H03 为透明盖后壁孔表。A-H02 增加 4 个后侧铰链盲预孔。安装孔均是假设，见[铰链说明](../references/hinges/README.md)。

第一册 A-P07 并列脚垫及固定座；底板标注四处 Ø12.4 通孔和底面盲预孔。固定座孔分布圆 Ø28、板上间隙及预孔为安装假设，未放行加工。

后板已标注横装 AC 开孔 48 × 28 mm、R3 和上下两孔 Ø4.5 / 孔距 40；插座法兰向后突出1.88 mm；当前整机图以后凸13.2 mm的合页为最深处，总深363.2 mm。插座外形与端子为保守包络，适用板厚、紧固与电气安全待实物确认。

当前默认参数与图中文字一致；修改 AC 开孔参数后，后板零件页和 A-H02 的孔标注会读取新参数，但第一册备料汇总中的 `StockNote` 仍可能保留默认尺寸。该问题尚未修复，详见[已知问题与待修项](current-work-handoff.md#已知问题与待修项)。电源线目前仅有[购买记录](../references/ac-inlet/README.md#购买链接)，未作为 CAD 零件或图册对象出图。

图册包含当前已有的开孔直径、定位坐标、后板沉台、倒相管壁厚及法兰信息。小数显示到 0.001 mm 是数值记录精度，**不是公差承诺**。防尘盖为成形外廓，未设计热弯展开、拼接工艺；未建模的螺孔、连接、公差和机芯安装接口仍未定义，不能直接作为生产加工图。

## 重新生成

先确认主 CAD 与两份 JSON 参数一致。本工具读取主文件的临时副本，校验结构及机芯参数快照，再恢复闭盖基准提取投影；不会重建或改写源 CAD。源 SHA-256 写入第一册首页，当前装配与历史参考分开统计，所有既有零件图号保持不变。

`drawing_data.py` 调用 `drawing_details.py` 提取六种板件（含透明盖后壁）的孔表、障板前表面法向投影及箱体中线临时剖面；`drawing_pack.py` 调用 `drawing_detail_pages.py` 排版。剖面只表示实际截面轮廓，不把包围盒边当作实体边。

下面的命令在仓库根目录执行；先按 [README](../README.md#整机重建) 设置 `FREECAD_RESOURCES`。默认输入输出相对脚本所在仓库解析。字体示例 `tmp/fonts/chinese-font.ttf` 是项目相对路径占位，需自行准备可嵌入的中文字体或替换为已有字体的相对路径：

```sh
# 在仓库根目录：提取 CAD 实体、精确尺寸与矢量投影。
PYTHONPATH="${FREECAD_RESOURCES:?请先设置 FreeCAD 运行环境}/lib" \
  "$FREECAD_RESOURCES/bin/python" tools/drawing_data.py

# 普通 Python 环境需要 reportlab、svglib；使用可嵌入的中文 TrueType 字体。
python3 tools/drawing_pack.py --font tmp/fonts/chinese-font.ttf
```

提取逻辑或数据结构变化后，须先重跑 `drawing_data.py`，不要直接用旧 JSON 排版。中间数据保存在忽略的 `tmp/pdfs/drawing-data.json`；最终目录为 `output/pdf/`。`--data`、`--output` 可覆盖默认路径。排版入口只读取指定 JSON，不重新校验其源 CAD 哈希；CAD 更新后必须重新提取。

请显式传入存在且可嵌入的中文字体。脚本保留的旧默认字体路径不保证可用，也不会自动搜索替代字体。当前 v0.9 交付使用 STHeiti Light；TrueType 集合 `.ttc` 需确认默认子字体可由 ReportLab 读取并覆盖所需字符。图中文字嵌入 PDF，阅读者不需要安装同一字体。

生成 PDF 需要 `reportlab`、`svglib` 和可嵌入的中文字体；PDF 回归测试另需 `pypdf`、`pdfplumber`，页面渲染需要 Poppler 的 `pdftoppm`。这些依赖运行于普通 Python，不要求装入 FreeCAD 自带环境。

验证：

```sh
PYTHONPATH="${FREECAD_RESOURCES:?请先设置 FreeCAD 运行环境}/lib" \
  "$FREECAD_RESOURCES/bin/python" -m unittest discover -s tests -v

# 在具有上述 PDF 依赖的普通 Python 中执行图册回归。
FREECAD_RESOURCES="${FREECAD_RESOURCES:?请先设置 FreeCAD 运行环境}" \
  python3 -m unittest discover -s tests -p test_drawing_pdf.py -v

# 每次生成后渲染检查，避免轮廓、尺寸线和文字错位。
mkdir -p tmp/pdfs
pdftoppm -scale-to 1500 -png output/pdf/01-assembly-and-enclosure.pdf tmp/pdfs/01
pdftoppm -scale-to 1500 -png output/pdf/02-acoustic-and-structure.pdf tmp/pdfs/02
```

FreeCAD 环境没有 `reportlab` 或 `svglib` 时会明确跳过 PDF 图册用例，须在依赖齐备的普通 Python 环境补跑；同时检查导览时使用 `-p '*_pdf.py'`。出图检查覆盖板孔坐标与实体空腔、底面盲孔深度、障板法向投影及斜面孔位、非默认参数、实体对象遗漏、复合对象拆分、斜板厚度、投影方向、源文件不变，以及 SVG 像素单位转换造成的 PDF 缩放偏差。PDF 用例另检查盲孔孔表输出及剖视不生成虚构包围盒边。完整出图回归需要将 `FREECAD_RESOURCES` 传入测试进程：它从当前保存 CAD 提取数据，在临时目录调用三册 PDF 命令行入口，核对 17／11／14 页、A/B/C-POS 安装位置表与保留零件图号，并确认源 CAD 未改写。该回归使用 ReportLab 自带字体验证执行流程；中文字体与实际页面布局仍需对交付 PDF 单独目视检查。未传入运行环境时该项会明确跳过。
