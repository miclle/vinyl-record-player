## 接手与重建

先核对工作区与 FreeCAD 未保存文档，保护手动修改。按 [基线重建](../README.md#v04-基线重建)执行生成、渲染、尺寸图和独立验证，再执行 [机芯核对版重建](selected-mechanism.md#后续适配与重建)。核对版读取已保存的基线，不会自动重建 JSON 修改。

使用 macOS FreeCAD 1.1.1，Python 路径 `/Applications/FreeCAD.app/Contents/Resources/bin/python`，`PYTHONPATH=/Applications/FreeCAD.app/Contents/Resources/lib`。GUI 保存用于保留颜色与可见性；纯 Python 可用于临时构建、测试和读回验证。用户本轮明确授权修复、提交并推送；授权范围包括此前未提交的 SC-2103 布局、交付物、文档和本轮验证修复。左右全频可封堵倒相接口目前仅为讨论建议，尚未建模。
