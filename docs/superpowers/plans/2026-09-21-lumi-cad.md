# LUMI CAD 实施记录

> 下方 v0.1 方案保留为历史记录；当前交付已按用户澄清更新为 v0.2：一个低音、两个高音。

**目标：** 根据官方图像和公开外廓尺寸重建外观，完成双全频单元布局，交付可再生 CAD 和验证证据。

**架构：** 参数 JSON 为尺寸来源；FreeCAD Python 使用毫米实体建模，按木壳、面板、唱盘、盖子、音响分组。原生文件保留独立零件，STEP 用于交换；安装部件为占位包络。

**技术：** FreeCAD 1.1.1、Open CASCADE、Python、SVG。

**依据：** `docs/design-basis.md`；用户要求先分析、定目标并立即执行，使用本地 CAD 工具完成，不增加计划审批步骤。

## 约束与评审重点

- 外廓宽 448.6 mm，深 345.5 mm；将官方高度 214.2 mm 暂作为闭盖总高。原图没有明确闭盖测量基准，必须注明。
- 转盘直径 300 mm；唱臂轴距 200 mm、有效长度 218 mm。唱臂细部为视觉包络，不是可加工的唱臂总成。
- 两个扬声器暂为左右各一个全频单元；不增加第三个低音单元。
- 板厚、结构分层、安装接口、声腔尺寸和铰链为设计假设。
- 验证实体有效性、数量与尺寸、播放几何、盖子净空、关键部件干涉和 STEP 回读。机械隔振和声学性能仍需样机验证。

## 文件与验收

- `cad/parameters.json`：公开参数和估算参数，可调后重建。
- `tools/build_model.py`、`tools/build.FCMacro`：实体建模及 GUI 导出。
- `tools/validate_model.py`：在 FreeCAD Python 中检查几何、回读 STEP。
- `cad/lumi-dual-driver.FCStd`、`cad/lumi-dual-driver.step`：闭盖装配。
- `cad/parts.csv`、`cad/validation.json`：零件与验证结果。
- `previews/`：实际 CAD 截图及尺寸 SVG。

验收运行：在 FreeCAD 中执行 `tools/build.FCMacro`；命令行用 FreeCAD 自带 Python 执行验证。预期所有实体合法、硬性尺寸匹配，未解决项在报告中直接列出，不据此宣称可生产。
